亚当斯降落伞干蝇

有史以来最容易辨认的干蝇图案。

亚当斯是一种诱饵图案,暗示许多蜉蝣。降落伞版本更容易绑,落地更柔和,比传统毛领版本更可见。

材料

钩子: 12-18号干蝇钩 绑线: 黑色6/0 (70旦尼尔) 尾巴: 灰白和棕色混合的毛领纤维 身体: 灰白和棕色混合的绒毛(或麝鼠绒毛) 翅柱: 白色牛尾或聚酯纱 毛领: 灰白和棕色混合,降落伞式缠绕

为什么有效

亚当斯是一种"通才"蜉蝣模仿:

  • 灰色暗示许多蜉蝣物种
  • 混合毛领创造逼真的移动
  • 降落伞式像真正的蜉蝣一样低坐在水中

分步说明

1. 线基座

  1. 将钩子固定在绑饵台上
  2. 在钩眼后开始绑线
  3. 缠绕到弯曲处并返回起点
  4. 创建光滑的线基座

2. 尾巴

  1. 选择灰白和棕色毛领纤维
  2. 将它们混合在一起(大约等量)
  3. 测量:尾巴长度=钩身
  4. 在钩身顶部绑制
  5. 长度应该约1/2钩身

3. 翅柱

  1. 剪一小簇牛尾或聚酯纱
  2. 长度应该约2个钩缝高
  3. 在钩身顶部绑制
  4. 让它直直站立
  5. 在柱前缠绕线保持垂直
  6. 向上缠绕线创造基础
  7. 缠回钩身

4. 尾巴和身体部分

  1. 将线缠绕到尾巴绑制点
  2. 向弯曲处建立轻微锥度
  3. 向前缠绕到柱

5. 身体

  1. 给线施加绒毛(少量!)
  2. 扭转制作锥形条
  3. 向前缠绕,创造轻微锥形的身体
  4. 在翅柱停止
  5. 身体应该纤细

6. 准备毛领

  1. 选择一个灰白和一个棕色毛领
  2. 去除基部的蓬松纤维
  3. 关键技巧: 将羽毛放在一起,茎对齐
  4. 将它们视为一根羽毛

7. 绑制毛领

  1. 将毛领羽毛靠在翅柱上
  2. 在柱基部绑制
  3. 光滑面应该朝您
  4. 尖端应该指向上

8. 缠绕毛领

  1. 用毛领钳抓住两个毛领羽毛
  2. 螺旋向下缠绕柱
  3. 做3-4圈,向下工作
  4. 每圈应该比上一圈低
  5. 在柱基部绑住
  6. 修剪多余毛领

9. 头部

  1. 缠绕线制作小头
  2. 收线
  3. 加一滴胶

专业技巧

柱材料选项

  • 牛尾: 传统,易于使用
  • 聚酯纱: 高度可见,漂浮永久
  • 安纶: 增加闪光
  • CDC: 更自然,更难使用

毛领选择

  • 具有硬纤维的干蝇质量毛领
  • 灰白和棕色尺寸相似
  • 羽毛长度应该向下绕柱3-4次

身体选项

  • 绒毛: 传统,虫状
  • 线身体: 更纤细,绑制更快
  • 羽茎身体: 更现实的分割

可见性

对于困难光线:

  • 使用明亮柱材料(橙色、粉色)
  • 给柱加一小滴油漆
  • 考虑"粉红女士"变化

常见问题

柱倾斜: 您的线缠绕没有适当支撑它。

身体太粗: 用更少绒毛 - 保持纤细。

毛领缠绕混乱: 花时间并均匀间隔。

柱太高: 它应该约2个钩缝高。

颜色变化

虽然传统亚当斯是:

  • 灰白&棕色毛领
  • 灰色身体

流行变化包括:

  • 雌性亚当斯: 红色或黄色身体
  • 降落伞亚当斯: 紫色或黄绿色身体提高可见性
  • 灰色亚当斯: 全灰白毛领

尺寸指南

  • 12号: 较大的水域,早季
  • 14号: 全能选择
  • 16号: 标准蜉蝣尺寸
  • 18号: 小蜉、蓝翅橄榄孵化
  • 20号: 小而选择性鳟鱼

钓亚当斯降落伞

呈现

  • 死漂: 最常见的方法
  • 立即修线: 消除拖拽
  • 长前导: 12-15英尺用于胆小的鱼

何时使用

  • 蜉蝣孵化: 鳟鱼上升时有效
  • 无孵化: 自信探索
  • 落虫: 晚钓的好

钓组

  • 单干蝇: 标准方法
  • 下钩若虫: 亚当斯下方18-24英寸
  • 干-下钩: 亚当斯带小若虫

为什么降落伞式?

比传统毛领的优势:

  1. 更容易绑: 身体上无毛领缠绕
  2. 落地更柔和: 惊吓较少鱼
  3. 更可见: 柱容易看到
  4. 低坐: 像真正的蜉蝣在水上
  5. 漂浮好: 柱保持飞蝇高骑

故障排除

飞蝇旋转: 毛领不均匀或柱偏离中心。

不漂浮: 柱太细或毛领太短。

难看到: 使用明亮柱材料或更大尺寸。

身体散开: 确保线缠绕牢固。

亚当斯系统

始终携带亚当斯降落伞:

  • 12号(早季,较大水域)
  • 14号(标准)
  • 16号(蜉蝣时间)
  • 18号(小孵化)

这是您的"信心蝇" - 有疑问时,绑亚当斯。

亚当斯降落伞钓到的鳟鱼比任何其他干蝇都多。掌握这个图案,您总会有一个能钓到鱼的飞蝇。
